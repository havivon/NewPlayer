# NewPlayer – נגן שמע פשוט לאנדרואיד

נגן שמע בלבד עם כפתורים גדולים.

- **כפתורים גדולים**: נגן/עצור, 10 שניות אחורה, 5 שניות אחורה, קובץ קודם/הבא
- **לחיצה אחת על מקום ריק במסך** עוצרת את הניגון
- **פורמטים**: MP3, M4A/AAC, FLAC, OGG/Opus/Vorbis, WAV, AMR ועוד
- **ניגון ברקע** – ממשיך לנגן גם כשהמסך כבוי או האפליקציה סגורה
- **מסך הנעילה והתראות**: נגן/עצור, 10 ו‑5 שניות אחורה (גם מאוזניות בלוטות')
- **זוכר איפה עצרת** – פותח את הקובץ האחרון מאותה נקודה
- אפשר לפתוח קובץ שמע ישירות ממנהל הקבצים / וואטסאפ דרך "פתח באמצעות"

## התקנה

כל דחיפה לגיטהאב בונה את האפליקציה אוטומטית (GitHub Actions).
את קובץ ההתקנה `NewPlayer.apk` אפשר להוריד ישירות לטלפון מעמוד ה‑Releases,
תחת `latest`. בהתקנה הראשונה יש לאשר "התקנה ממקורות לא ידועים".

## בנייה מקומית

```
./gradlew assembleRelease
```

דרוש Android SDK (API 35) ו‑JDK 17.
